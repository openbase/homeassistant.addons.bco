# BCO Home Assistant Addons

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fopenbase%2Fhomeassistant.addons.bco)

A collection of add-ons to integrate BaseCubeOne (BCO) into any Home Assistant instance. The following four add-ons are required:

1. **BCO Core** The heart of BCO, providing all essential services.
2. **BCO Middleware** Offers MQTT as middleware, designed to facilitate communication between all BCO components.
3. **BCO Userinterface** Delivers the BCO user interface as a local web application within the network.
4. **BCO Home Assistant Gateway** Acts as the gateway between BCO and Home Assistant, managing device, area, entity, and service synchronization between both systems.
  
Find more details about BaseCubeOne here: https://basecubeone.org.
